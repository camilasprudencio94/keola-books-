# Keola Books

Catálogo digital da Keola Books.

## Estrutura

- index.html — página principal
- style.css — visual do site
- app.js — busca, filtros e funcionalidades
- catalogo.json — catálogo completo de livros

## Publicação

O site pode ser publicado gratuitamente pelo GitHub Pages.

Settings → Pages → Deploy from a branch → main → / (root)

## Catálogo

O catálogo atualmente contém 362 livros.

Para atualizar o catálogo, altere o arquivo catalogo.json e faça um novo commit.
